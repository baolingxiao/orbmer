# Orbmare 后台使用指南（员工版）

本指南面向不写代码的运营同事。

## 如何登录

1. 打开管理员发给你的后台地址（例如 `https://admin.orbmare.com`）。
2. 输入工作邮箱和密码（至少 14 位）。
3. 连续输错会被临时锁定，请稍后再试或联系 Super Admin。

普通顾客账号无法登录此后台。

## 如何新增商品

1. 左侧进入 **商品**。
2. 点 **新建商品**。
3. 选择渠道：
   - **3D打印馆**：出现在店铺结账。
   - **甄选馆**：出现在国家馆 / 发现页。
4. 填写中英文名称、价格、材料、图片路径、故事。
5. 状态先选 **草稿**，点保存。

## 如何上传图片

1. 打开 **媒体库**。
2. 点 **上传文件**，选择图片（JPG/PNG/WebP/GIF，也可 PDF/短视频）。
3. 上传后点 **复制路径**。
4. 回到商品或材料编辑页，把路径粘贴到图片字段（通常以 `/assets/` 开头）。

## 如何保存草稿

商品状态选 **草稿** 后保存。草稿不会出现在顾客网站。

## 如何提交审核

将状态改为 **提交审核** 后保存。没有「发布」权限的同事不能直接上架；系统会阻止直接发布。

## 如何发布

需要有发布权限的管理员：

1. 检查内容、价格、图片、物流说明。
2. 将状态改为 **已发布** 并保存。
3. 打开前台对应页面刷新确认。

甄选商品 → 国家馆 / 发现页；3D 商品 → `/shop/`。

## 如何修改库存

1. 打开 **库存**，或在商品列表点库存操作。
2. 选择：
   - **按单采购**：不维护具体件数
   - **实物库存**：填写现有数量与补货线
   - **暂停供应**：前台不可购买
3. 保存。结账以服务器库存为准。

## 如何管理品牌 / 材料 / 国家

左侧 **品牌 / 材料 / 国家馆**：

1. 新建或编辑。
2. 填写中英文名称、简介、故事、图片。
3. 状态设为 **已发布** 后，前台接口才会读取。

材料内容如有不确定处，请标明需核实，不要写成已验证事实。

## 如何查看订单

打开 **订单**：可搜索订单号/邮箱，更新履约状态与物流单号。不要在备注中粘贴完整银行卡号。

## 权限不足时怎么办

- 页面菜单看不到：说明你的角色没有该模块权限。
- 保存时提示没有权限：请联系 Super Admin 调整角色，不要共用别人的账号。
- 需要发布/改成本/导出客户：分别需要发布、财务、客户导出权限。

## 首页文案

**首页文案** 可改 Hero 标题与按钮文字。改完保存后刷新官网首页查看。
